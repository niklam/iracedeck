# Pit Crew toggle keys hide their title by default

> **Issue:** [#1479](https://github.com/niklam/iracedeck/issues/1479) · **Supersedes:** _none_ · **Superseded by:** _none_
>
> Point-in-time design record. The code and `.claude/rules/` are the truth; this is not documentation.

Pit Crew's keys draw a title: `RACE ENGINEER`, `RADAR` and `CORNER NAMES` on the three toggles, and `VOL +` / `VOL −` over the volume on the two Radar Volume keys. The toggles also draw a green or red status bar that already says whether the feature is on. This hides the title on the three toggles by default, as Car Control's Pit Speed Limiter and Starter do, and keeps it on Radar Volume, where it is the readout, as DRS and Push to Pass keep theirs. The issue carries the request; this records how.

## Why the titles show today

`pit-crew.svg`'s `<desc>` already says `"showTitle": false`. A key's `showTitle` resolves per-key override → global title setting → icon `<desc>` default → `TITLE_DEFAULTS` (`resolveTitleSettings` in `@iracedeck/icon-composer`), and the global step is skipped only for a field the icon lists in `locked`. The global **Show title text on key** checkbox (`titleShowTitle`, in `global-title-defaults.ejs`) defaults to on. So wherever that setting has a value, it outranks the icon's unlocked `false`, and the title shows. Car Control's tri-state icons lock `showTitle` for exactly this reason, in both directions: Pit Speed Limiter and Starter lock it hidden, while DRS, Push to Pass and Ignition lock it shown.

## Behaviour

- **Race Engineer, Radar, Corner Names:** the title is hidden by default and the artwork grows into the room it leaves above the status bar (`computeGraphicArea` already sizes the artwork from the resolved title, so no layout code changes). The global Show title setting no longer applies to these three. A per-key **Title Overrides → Show Title** still turns the title on, and then the artwork shrinks back as it does today.
- **Radar Volume (up and down):** the title is shown by default and the global Show title setting no longer applies to it either, because the title is the volume readout, not a label: a deck with global titles off would otherwise show a volume key with no volume. A per-key override still hides it.
- **Existing keys change on upgrade.** A toggle key with no per-key title override loses its title; one whose user turned the title on per key keeps it. The changelog says so, naming the per-key setting that brings it back. No settings migration is needed: nothing stored changes meaning, only the icon default and its lock.

## Architecture

- **Lock it in the icon, not in code.** The default and the lock live in the template's `<desc>` title metadata, where every other icon keeps them, so the title resolution, the PI's notion of the default and the icon previews all read one source.
- **A template per title default.** `resolveTitleSettings` takes its defaults from the template it is given, and `pit-crew.svg` serves all four modes today. The three toggles keep `pit-crew.svg`, with `"showTitle": false`, `"position": "top"` and `"locked": ["showTitle", "position"]`. The two Radar Volume modes get `pit-crew-radar-volume.svg`, the same template with `"showTitle": true` and `"locked": ["showTitle"]`. `pit-crew.ts` passes the mode's template to `resolveTitleSettings` and `renderIconTemplate`. This follows Car Control, which already has one template per tri-state key (`car-control-pit-limiter.svg` and the rest). The colours and border in the new template's `<desc>` are copied from `pit-crew.svg`, so `icon-defaults.json` gains a `pit-crew-radar-volume` entry identical to `pit-crew`'s.
- **The toggles lock `showTitle` and `position` (top); Radar Volume locks only `showTitle`.** The toggles' status bar is drawn over y 100–144 after the title, so a title at the default bottom position would come back hidden under it when a user turns it on per key. The top position is Car Control's precedent for Pit Limiter and Starter. Font size and bold still follow the global title settings. Radar Volume has no status bar, so its position stays free. (Amended 2026-11-09 from the implementation.)

## Out of scope

- Pit Crew's other title fields, and any other action's titles.
- A global "titles off for toggle keys" setting.
- Changing the Radar Volume readout itself, for example drawing the percentage in the artwork so its title could go too.

## Testing

- **Unit:** for each toggle mode, the title is hidden with the global Show title on, off and unset, and shown with a per-key Show Title override; for each Radar Volume mode, the title is shown with the global setting on, off and unset, and hidden with a per-key override. The artwork's area is larger on a toggle key with no title than with one.
- **Icons:** `icon-defaults.json` matches its generator, and the new template's colour entry equals `pit-crew`'s.
- **By hand:** on Stream Deck and Mirabox, place each of the five keys with the global Show title on. The three toggles show no title and larger artwork above the status bar; the volume keys show `VOL +` / `VOL −` and the percentage. Turn on a toggle's per-key Show Title and see the title return. Turn the global setting off and see the volume keys keep their readout.
