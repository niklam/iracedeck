# @iracedeck/replay-engine

The iRacing replay engine (#1467): the command gate, the cursor, jump playback, seek, the paced search, the speed state, the camera-switch waiter and the lap walks, moved out of `@iracedeck/iracing-actions` so the key, the dial and the legacy actions share one engine. It depends on `@iracedeck/iracing-sdk`, `@iracedeck/replay-store`, `@iracedeck/logger` and `@iracedeck/app-constants` and on nothing else in the workspace; what it needs from the deck layer and the settings is injected once by `plugin-runtime`'s `initReplay` phase through `configureReplayEngine`, and an ESLint block (proved by `scripts/replay-engine-boundary.test.mjs`) refuses the rest. The design is `docs/superpowers/specs/2026-10-20-issue-1467-replay-engine-package.md`; the module map follows when the code has moved.
