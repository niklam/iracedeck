## Reporting Issues

Found a bug or have a feature idea? [Open an issue](https://github.com/iracedeck/iracedeck/issues/new/choose) on GitHub. For a bug, include:

- What you expected to happen
- What actually happened
- Steps to reproduce it
- Your iRaceDeck version
- Your deck and its host software, with versions: a Stream Deck with the Stream Deck software, a Mirabox deck with HotSpot StreamDock or VSD Craft, or a Ulanzi Deck with UlanziStudio

Questions are better asked on [Discord](https://discord.gg/c6nRYywpah) than in an issue. A security vulnerability is never reported in a public issue: follow the [security policy](https://github.com/iracedeck/iracedeck/blob/master/SECURITY.md) instead.

## Submitting Code

Anyone can pick up an issue that is not assigned to anyone: comment on it to claim it, and it gets assigned to you. Everything else you need, from the development setup and the checks to run to changelog fragments and the pull request itself, is in [CONTRIBUTING.md](https://github.com/iracedeck/iracedeck/blob/master/CONTRIBUTING.md) in the repository. The [Setup](/docs/development/setup/) page covers building the plugin and linking it to your deck host.

## Community

- **[Discord](https://discord.gg/c6nRYywpah)**: the main community hub for discussion, support and feedback
- **[Reddit](https://www.reddit.com/r/iRaceDeck/)**: r/iRaceDeck for tips, showcase and discussion
- **[GitHub](https://github.com/iracedeck/iracedeck)**: source code, issues and pull requests

Everyone taking part follows the [Code of Conduct](https://github.com/iracedeck/iracedeck/blob/master/CODE_OF_CONDUCT.md).
