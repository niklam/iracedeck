# @iracedeck/website

The Astro + Starlight site at iracedeck.com. Its conventions, page layout and deployment are in the `website` skill; action pages follow `.claude/rules/website-action-docs.md`.

## Generated data

- `build`, `dev` and `typecheck` regenerate the gitignored artifacts first: the icon gallery (`generate:gallery`), and for `build` and `dev` also the changelog (`generate:changelog-json`) and the voice catalog (`generate:voice-catalog-json`).
- `src/data/pack-reference.json` is the exception: it is committed and freshness-tested, built by `pnpm generate:pack-reference`. Its shape is mirrored by hand in `src/pack-reference-types.ts`, because the site imports nothing from the engine.
- The website is sim-neutral (`SIM_NEUTRAL_PACKAGES` in `eslint.config.js`), and so must be everything the gallery generator (`scripts/generate-icon-gallery.mts`) loads by relative path from `iracing-actions`: the dial surfaces' sim-free `*-dial-render.ts` modules and the shared drawing they reach, never a `*-dial-surface.ts` or anything that imports `deck-iracing` or `iracing-sdk`. The lint block refuses every package outside that list by static or type import, but cannot see a relative path, a dynamic `import()` or `require`, nor an `.mdx` page, which ESLint never reads; `scripts/cross-package-reach.test.mjs` walks the runtime imports of every source in the website (and every other sim-neutral package) — an `.astro` component or `.mdx` page read by its raw text, never parsed: every literal specifier in it, in markup, prose or a fence as much as in its frontmatter or a script, counted as a load (a relative or root-absolute one that resolves followed, an `@iracedeck/` one checked by name), and a computed load (an `import(` or `require` of anything but one string literal, any `createRequire`, a glob of module code) failing as unread — and fails on any workspace package outside that list (#1662). A page that only mentions a sim package in its text fails too: `NAMED_NOT_LOADED` in that test names each such literal with the reason it loads nothing.
