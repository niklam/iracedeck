In practice and test sessions the Race Engineer now calls each sector start as you reach it, *"Sector two."*, *"Sector three."*, using the track's own sectors and the same **Corner call lead** as the corner names; sector one at the start/finish line is not called, a named corner due right after a sector start takes its place, and the calls can be switched off under **Race Engineer Callouts → Corner Names and Sectors**. See [Sector starts](/docs/actions/audio-voice/pit-crew/#sector-starts-practice--test).
