**The Race Engineer grew a personality.** Both of iRaceDeck's own voices, **Shawn** and **Shawn (Short callouts)**, were re-recorded on ElevenLabs' newest voice model, so every call sounds more natural and lines put together from several clips, such as lap times, run together more smoothly. Each voice that iRaceDeck installed for you downloads the update once at the next plugin start; see [Race Engineer Voices](/docs/features/race-engineer-voices/#iracedecks-own-voices).
