**Replay Markers** has a new **Add / Delete Marker** mode: one key that shows and does Delete Marker while a marker is within its Delete Window and Add Marker otherwise, switching its icon as the replay plays; once the key shows Delete after you add a marker, a press undoes it. See [Replay Markers](/docs/actions/view-camera/replay-markers/#add--delete-marker).
