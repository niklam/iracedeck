**Disconnected Keys**: iRaceDeck can now dim every key that needs iRacing while iRacing isn't running, with a small disconnected badge in the corner, so you can see at a glance which keys can't do anything yet. Turn on **Dim keys that need iRacing** on the Settings window's **Appearance** tab; it is off by default, keys dim about 5 seconds after iRacing closes and return to normal as soon as it connects, and pressing a dimmed key still sends the press. Pit Crew, Switch Profile, the Race Engineer and Radar volume keys and Capture CPU Profile keep their normal look. It replaces the **Disable buttons when iRacing is not connected** option, which no longer did anything. See [Disconnected Keys](/docs/getting-started/settings/#disconnected-keys).
