**Black Box Selector** has a new **Toggle Size** mode that switches the open black box between iRacing's small and large size, and on a Stream Deck+ dial or Mirabox knob a press can now do the same. iRacing ships its Toggle Black Box Size control without a key, so assign one in iRacing and set the same key in iRaceDeck. See [Black Box Selector](/docs/actions/driving/black-box-selector/).
