**Replay Markers** Delete Marker keys and the marker dial now have a **Delete Window** setting, 1 to 60 seconds (10 by default, as before), for how far from a marker a delete reaches, and a Delete Marker key now turns grey whenever a press would delete nothing. See [Replay Markers](/docs/actions/view-camera/replay-markers/#delete-marker).
