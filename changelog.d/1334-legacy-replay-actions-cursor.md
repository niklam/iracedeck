Keys still set up with the older Replay Navigation, Replay Speed and Replay Transport actions, which Replay Control replaced, now stop a running **Jump to Fastest Lap** the way Replay Control's own keys do, instead of fighting it for the replay. A Replay Markers jump straight after one of them also measures from where the replay now is, not from the marker it was last headed to. See [Replay Control](/docs/actions/view-camera/replay-control/#jump-to-fastest-lap).
