The Race Engineer's **Fuel margin (laps)** setting now defaults to 0 laps, so the fuel counts and the *"Box this lap for fuel."* call no longer sometimes come a lap earlier than needed; the spoken count is already rounded down to whole laps. Installs that still have the old default of 0.3 are moved to 0 by the update, including anyone who picked 0.3 on purpose, who can set it back on the Settings window's **Race Engineer** tab. See [Laps of fuel left](/docs/actions/audio-voice/pit-crew/#laps-of-fuel-left).
