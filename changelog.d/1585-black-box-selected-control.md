**Black Box Selector** has a new **Selected Control** mode that works the controls inside the open black box: select the next or previous control, increase or decrease it (repeating while held), or toggle it. On a Stream Deck+ dial or Mirabox knob, a new **Mode** setting turns the dial into a control selector or adjuster, where by default a press toggles the selected control and, on a Stream Deck+, a long press switches between selecting and adjusting. iRaceDeck ships the five new bindings without keys, so assign them in iRacing and set the same keys in iRaceDeck. See [Black Box Selector](/docs/actions/driving/black-box-selector/).
