**Toggle UI Elements** has a new **Minimal Drive UI** mode that switches iRacing's driving UI between its normal layout and Minimal, which shows only your pinned widgets and the ones iRacing requires (it needs at least one pinned widget). iRacing ships its Toggle Minimal Drive UI control without a key, so assign one in iRacing and set the same key in iRaceDeck. See [Toggle UI Elements](/docs/actions/cockpit/toggle-ui-elements/).
