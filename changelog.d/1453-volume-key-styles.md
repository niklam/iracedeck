**Audio Controls** and **AI Spotter Controls** volume keys get the paired +/− key styles the setup actions have, so an up and a down key side by side read as one volume control, and holding a key in any style but Legacy keeps stepping. Race Engineer and Radar keys show their live level, or **OFF** while the feature is switched off; iRacing reports no master, voice chat or spotter volume, so those keys show a big + or − with a one-word label. New keys start on **Split** and existing keys keep their look. See [Audio Controls](/docs/actions/audio-voice/audio-controls/#key-styles--paired--buttons) and [AI Spotter Controls](/docs/actions/audio-voice/ai-spotter-controls/#key-styles--paired--buttons).
