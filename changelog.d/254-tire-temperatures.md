**Session Info** has a new **Tire Temperatures** item: the temperatures your tires came off the last run with, all four on one key or one tire's outside, middle and inside zones, colored by a temperature window you set in °C or °F. It is a pit-stop reading, not a live gauge, because iRacing only updates tire temperatures when the car comes in. See [Session Info](/docs/actions/display-session/session-info/#tire-temperatures).
