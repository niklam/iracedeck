Pressing the **Pit Crew** **Corner Names** key, or the Race Engineer **Test** button in the Settings window, while the engineer is talking no longer leaves him silent for the rest of the session: the confirmation now cuts in and the line it interrupted picks up again after it, while a flag or spotter call is never cut, so the confirmation is skipped then and the key still toggles. See [Pit Crew](/docs/actions/audio-voice/pit-crew/#corner-names).
